# DraftHelper

Помощник для разработчиков и тестировщиков услуг ЕПГУ. Показывает значения из сохранённого черновика для текущего экрана, помогает работать с циклами и записывает прохождение с комментариями.

**Текущая версия — 3.6.0.**

[Скачать скрипт](https://github.com/Ex4ak/DraftHelper---Public-Releases/raw/refs/heads/release/DraftHelper.js) · [Изменения версий](CHANGELOG.md) · [Зафиксированная версия 3.6.0](https://github.com/Ex4ak/DraftHelper---Public-Releases/tree/v3.6.0)

## Запуск

1. Откройте страницу услуги в браузере.
2. Откройте инструменты разработчика клавишей **F12**, затем вкладку **Console**.
3. Откройте скачанный `DraftHelper.js` в текстовом редакторе. Скопируйте всё содержимое, вставьте в консоль и нажмите **Enter**.
4. В разделе **«Данные»** выберите файл черновика либо вставьте его текст и нажмите **«Загрузить текст»**.
5. Продолжите прохождение услуги. После очередного ответа сервера в **«Подсказках»** появятся значения для полученного экрана.

Для прогноза переходов и наблюдения BackRestCall дополнительно загрузите JSON исходника услуги в разделе «Данные».

Перед заменой версии сохраните журнал и нажмите **«Удалить помощник»**, затем выполните новый файл. При переходе с V2 сначала перезагрузите страницу. После перезагрузки помощник и исходные данные нужно загрузить заново.

## Возможности

- **Подсказки по черновику.** Значения компонентов текущего экрана, источник ответа и копирование. Для дат, адресов и справочников используются читаемые форматы.
- **Циклы.** Обзор полей начального экрана по всем элементам и ручной выбор элемента исходного черновика. Поддерживаются ChildrenList и RepeatableFields.
- **Прогноз переходов.** Проверка поддерживаемых условий screenRules и cycledScreenRules по текущим ответам или черновику. Следующие экраны подписаны названием и ID.
- **Журнал прохождения.** Последовательность полученных экранов, ручные отметки и комментарии.
- **Архив прогонов.** Экспорт журнала в TXT и просмотр сохранённых файлов без редактирования.
- **Диагностика.** Последние 50 подробных снимков ответов, невидимые экраны с Redirect и logicComponents.
- **BackRestCall.** Появление и изменение результата, связь с объявлениями экранов в исходнике, сравнение с черновиком и копирование значений.

## Разделы панели

| Раздел | Содержимое |
|---|---|
| Подсказки | Текущий экран, цикл, значения полей и прогноз |
| Текущий прогон | Шаги, отметки, комментарии, BackRestCall и экспорт |
| Архив | Загрузка и просмотр TXT-прогонов |
| Диагностика | Снимки ответов и сведения о компонентах логики |
| Данные | Загрузка черновика и исходника услуги |

Окно перемещается за заголовок. Размер меняется за правый или нижний край и нижний правый угол. Боковое меню сворачивается до иконок, окно — до заголовка.

**«Стоп»** приостанавливает подсказки; страница и запись ответов продолжают работать. **«Обновить»** перерисовывает подсказки без отправки нового запроса.

## Работа с циклами

На начальном экране цикла доступны все элементы исходного черновика или один выбранный элемент. Внутри цикла проверяйте выбор элемента при переходе к следующей итерации. Если контекста недостаточно, помощник не угадывает значение.

## Отметки и сохранение прогона

Кнопка статуса шага переключается по кругу:

- **Зелёный — «Проблем нет».** Статус по умолчанию, без автоматической проверки результата.
- **Жёлтый — «Вопрос к DEV».** Требуется уточнение у разработчика.
- **Красный — «Ошибка при тестировании».** Обнаружена проблема.

Комментарий сохраняется в памяти при вводе. Кнопка **«Сохранить TXT»** выгружает весь список шагов с названиями экранов, цветами и комментариями. Перед следующим прогоном сохраните файл и нажмите **«Очистить журнал»**. Загрузка нового черновика сама по себе журнал не очищает.

В «Архиве» можно открыть несколько сохранённых прогонов. Поддерживается формат DraftHelper Run v1, размер файла — до 10 МБ.

## Поддержка компонентов

Предусмотрено форматирование дат, адресов, Lookup, DropDown, DocInput, MapService и сведений FileUploadComponent. Простые строки, числа и логические значения отображаются как текст. Поддержка зависит от структуры сохранённого значения.

| Компонент | Что отображается |
|---|---|
| MaritalStatusInput | Дата и номер актовой записи, орган регистрации |
| PaymentTypeSelector | Выбор, сумма, номер и ID счёта; копируется selected при наличии |
| UnusedPayments | УИН, название платежа, сумма, адрес и ссылка |
| PaymentScr | УИН, назначение, сумма и ID счёта |
| PoddFileUpload | Имена файлов, признаки подписи и удаления, ошибки |

Суммы платежей показываются в исходных единицах. Сведения о вложениях не позволяют восстановить сами файлы.

## Ограничения

- Помощник работает в текущей вкладке и наблюдает ответы XHR и fetch после запуска. Уже завершённые запросы не восстанавливаются.
- Поля заполняет и переходы выполняет тестировщик. Подсветки ответов на странице, автоматического заполнения, остановки и подмены ответов нет.
- Прогноз поддерживает не все условия услуги. Недостаток данных отмечается вопросительным знаком; неотправленные значения полей в прогноз по текущему ответу не входят.
- Наблюдение BackRestCall начинается после подключения исходника. Повторный вызов с тем же значением не обнаруживается. Объявление компонента в исходнике само по себе не доказывает прохождение экрана.
- Хранятся последние 100 событий BackRestCall. В TXT эти события и полные ответы компонентов не включаются.
- Состояние находится в памяти страницы. Перед перезагрузкой или удалением помощника сохраните журнал.

Черновики, исходник услуги и ответы обрабатываются локально в браузере. Собственных сетевых запросов DraftHelper не отправляет.

## Обратная связь

В сообщении об ошибке укажите версию DraftHelper, тип компонента, шаги воспроизведения и ожидаемый результат. Используйте обезличенные примеры. Не публикуйте пользовательские черновики, платёжные реквизиты и ответы с персональными данными.
